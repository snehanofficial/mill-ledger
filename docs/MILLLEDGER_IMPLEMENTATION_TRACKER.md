## 1. Priority Legend

- **P0**: Official CDI benchmark, mandatory core workflow, data integrity, security, and correctness.
- **P1**: Strongly preferred features, complete CRUD + protected UI, and important supporting functionality.
- **P2**: Optional stretch goals, UX enhancements, and secondary exports.
- **P3**: Deferred or low-priority polish.

## 2. Status Legend

- `VERIFIED`: End-to-end verified across server, DB, authorization, protected UI, and passing tests.
- `PARTIAL`: Meaningful implementation exists, but required server/UI/auth/validation/test slices remain incomplete.
- `TODO`: Not implemented (no meaningful working implementation).
- `BLOCKED`: Blocked by an unresolved policy/decision or external dependency.
