# Frontend Feature Preservation Matrix

**Date:** 2026-11-27  
**Purpose:** Complete Phase 1 audit of every existing MillLedger route, feature, CRUD action, and permission, mapped to its target destination in the UX Blueprint.

## Classification Legend

- `PRESERVE`: Working capability retained at its current route with visual/shell alignment.
- `REORGANIZE`: Working capability moved or promoted to a clearer route/navigation group (with redirect/alias if URL changes).
- `REWORK`: Capability exists (often inside a modal or monolithic page) and must be extracted into dedicated list -> detail -> action pages or role-specific views.
- `BROKEN`: Existing UI control is non-functional or points to a missing route.
- `MISSING`: Required by UX Blueprint / existing backend endpoint without dedicated frontend route.
- `DEFERRED_WITH_REASON`: Intentionally excluded or parked with documented justification.
