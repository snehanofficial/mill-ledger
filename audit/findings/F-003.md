# Finding F-003: Silent Seed Failure on Prisma 7 CLI `prisma db seed`

**ID**: F-003  
**Title**: README command `pnpm --filter @mill-ledger/server prisma db seed` fails silently without seeding records  
**Severity**: P1  
**Category**: Core Workflow / Seed Reliability  
**Standard Refs**: MLD-001 Baseline Operations, Prisma 7 Migration Guide  
**Status**: OPEN  

---

### Expected (source)
`README.md` line 34 specifies:
`pnpm --filter @mill-ledger/server prisma db seed`
Expected to populate users, organizations, warehouses, items, and benchmark opening balances.

### Actual (evidence links)
- Running the exact command outputs:
  ```
  ⚠️ No seed command configured
  To seed your database, add a seed property to the migrations section in your Prisma config file.
  ```
- Command exits with code 0, but 0 rows are inserted into the database.
- Checking `SELECT count(*) FROM "user";` returns 0.
- Working undocumented command is `pnpm --filter @mill-ledger/server run db:seed`.
- Evidence log: [audit/evidence/04-prisma-db-seed.txt](file:///home/snehan/projects/web/mill-ledger/audit/evidence/04-prisma-db-seed.txt)

### Delta
Expected seeded database; observed empty database due to missing `migrations.seed` configuration in `server/prisma.config.ts`.

### Impact
Any developer or automated deployment script executing the documented README quickstart steps will end up with an unseeded, empty database where login and workflows cannot function.

### Repro Steps
1. Run `pnpm --filter @mill-ledger/server prisma migrate deploy` on clean database.
2. Run `pnpm --filter @mill-ledger/server prisma db seed`.
3. Check `SELECT count(*) FROM "user";`. Count is 0.

### Root Cause
File: [server/prisma.config.ts](file:///home/snehan/projects/web/mill-ledger/server/prisma.config.ts#L4-L8)
Prisma 7 requires `migrations: { seed: 'tsx ./prisma/seed.ts' }` in `defineConfig()`, but only `schema` and `datasource.url` are declared.

### Recommended Fix (DO NOT APPLY - AUDIT ONLY)
Add `migrations: { seed: 'tsx ./prisma/seed.ts' }` to `server/prisma.config.ts` or update README to `pnpm --filter @mill-ledger/server run db:seed`.

### Regression Test to Add
Integration test executing `prisma db seed` and verifying row count > 0.
