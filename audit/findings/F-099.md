# F-099: Broken Production Dockerfile: Missing `tsconfig.json` Causes Build Failure, Unpruned DevDependencies, and Static Client Files Never Served by API Server

- **ID**: F-099
- **Title**: Broken Production Dockerfile: Missing `tsconfig.json` Causes Build Failure, Unpruned DevDependencies, and Static Client Files Never Served by API Server
- **Severity**: P1
- **Category**: Operations & Container Packaging
- **Standard Refs**:
  - 12-Factor App (Factor V: Build, release, run)
  - CIS Docker Benchmark v1.6.0 (Section 4 - Container Images and Build Files)

---

## Expected (Source)
- **Source**: `Problem_Statement_Winter_Internship_Application_2026.md` & Production Deployment Baseline:
  - The application container must build cleanly via standard container engines (`docker build`).
  - Production container images must be minimal, excluding extraneous build tools and `devDependencies` (e.g. Playwright, Vitest, Oxlint).
  - The runtime image must serve both the Express API and the built client SPA assets on the designated application port (`PORT=4000`).

---

## Actual (Evidence Links)
1. **Docker Build Failure**:
   - [`Dockerfile:23`](file:///home/snehan/projects/web/mill-ledger/Dockerfile#L23):
     ```dockerfile
     COPY shared/ ./shared/
     COPY client/ ./client/
     COPY server/ ./server/
     COPY tsconfig.json ./
     ```
   - Running `docker build -t mill-ledger:audit-test .` fails immediately with:
     ```
     ERROR: failed to build: failed to solve: failed to compute cache key: failed to calculate checksum of ref ...: "/tsconfig.json": not found
     ```
     The repository uses package-level `tsconfig.json` files (`client/tsconfig.json`, `server/tsconfig.json`, `shared/tsconfig.json`) and has **no root `tsconfig.json`**.
2. **Unpruned Development Dependencies**:
   - [`Dockerfile:47`](file:///home/snehan/projects/web/mill-ledger/Dockerfile#L47):
     ```dockerfile
     COPY --from=builder /app/node_modules ./node_modules
     ```
     The runner stage directly copies the entire `/app/node_modules` from the builder without executing `pnpm prune --prod` or installing production-only dependencies. Heavy testing dependencies (Playwright, Vitest, Oxlint, Prettier, TypeScript) are bloated into the production runtime container.
3. **Frontend Assets Never Served by Runtime Server**:
   - [`Dockerfile:52`](file:///home/snehan/projects/web/mill-ledger/Dockerfile#L52) copies `/app/client/dist` into the runner stage, and [`Dockerfile:64`](file:///home/snehan/projects/web/mill-ledger/Dockerfile#L64) executes `node server/dist/index.js`.
   - However, in [`server/src/app.ts:39-57`](file:///home/snehan/projects/web/mill-ledger/server/src/app.ts#L39-L57), the Express application only registers `/api/v1` routes and `/api/health`. There is **zero `express.static()` middleware** or fallback handler to serve `client/dist/index.html`.
   - When a browser accesses `http://localhost:4000/`, Express returns HTTP 404 Cannot GET /.

---

## Delta
- The Dockerfile does not build due to a missing root `tsconfig.json`. Even if patched, the resulting image contains all devDependencies, and the backend server does not serve the client bundle copied into the container.

---

## Impact
- **Deployment Blocker**: Any automated containerized deployment (Docker Compose, ECS, Kubernetes, Cloud Run) fails during the build step.
- **Image Bloat & Attack Surface**: Copying full build `node_modules` introduces unnecessary attack surfaces and multi-hundred-megabyte image bloat.
- **Broken Frontend Delivery**: Operators deploying via the provided `docker-compose.yml` will find the frontend completely inaccessible.

---

## Repro Steps
1. Execute `docker build -t mill-ledger:audit-test .` from the repository root.
2. Observe fatal error: `COPY tsconfig.json ./: "/tsconfig.json": not found`.
3. Inspect `Dockerfile` lines 47 and 52 against `server/src/app.ts`.

---

## Root Cause
- `Dockerfile` was authored with assumptions of a root `tsconfig.json` and assumed Express would serve static client assets without configuring `express.static(path.resolve('client/dist'))`.

---

## Recommended Fix
1. Remove line 23 (`COPY tsconfig.json ./`) from `Dockerfile`.
2. In Stage 1, run `pnpm --filter @mill-ledger/server --filter @mill-ledger/shared deploy --prod /app/prod-deploy` or execute `pnpm prune --prod` to isolate production dependencies.
3. In `server/src/app.ts`, add static asset serving for `client/dist` in production mode with a SPA fallback to `index.html` for non-API routes.
