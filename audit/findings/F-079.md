# F-079: Unused Cyrillic/Vietnamese Font Subsets Bundled While Required Tamil Font Subset is Missing

- **ID**: F-079
- **Title**: Unused Cyrillic/Vietnamese Font Subsets Bundled While Required Tamil Font Subset is Missing
- **Severity**: P3
- **Category**: Font Optimization / Localization Performance
- **Standard Refs**:
  - `audit/01-expected-spec.md` (REQ-053 Bilingual Interface: Tamil & English)
  - W3C Web Fonts Optimization Best Practices (Unicode-Range Subsetting)

---

## Expected (Source)
- **Source**: `audit/01-expected-spec.md` (REQ-053), Phase 10 Audit Prompt Requirement #2.
- For a bilingual application targeting Tamil and English users in Tamil Nadu, India, font assets should be strictly subsetted to Latin and Tamil unicode ranges (`U+0B80-0BFF`). Non-applicable language subsets (e.g. Cyrillic, Vietnamese) should not be shipped in production bundles.

---

## Actual (Evidence Links)
- **Evidence**:
  - Static asset inventory in `client/dist/assets/`:
    - `geist-cyrillic-ext-wght-normal-DjL33-gN.woff2` (7.25 KB)
    - `geist-vietnamese-wght-normal-6IgcOCM7.woff2` (7.82 KB)
    - `geist-cyrillic-wght-normal-BEAKL7Jp.woff2` (14.73 KB)
    - `geist-latin-ext-wght-normal-DC-KSUi6.woff2` (16.13 KB)
    - `geist-latin-wght-normal-BgDaEnEv.woff2` (28.71 KB)
  - Total bundled font size: **74.64 KB raw**.
  - Font import in [`client/src/index.css`](file:///home/snehan/projects/web/mill-ledger/client/src/index.css#L1):
    `@import "@fontsource-variable/geist";`
  - Font inspection for Tamil: No Tamil font or subset (e.g. Noto Sans Tamil) is bundled or imported.

---

## Delta
1. **Unnecessary asset bloat**: 45.9 KB of Cyrillic, Cyrillic-ext, Vietnamese, and Latin-ext WOFF2 font files are bundled into the application distribution despite having zero usage in an English/Tamil ERP.
2. **Missing core language font**: While the application features a full Tamil language toggle (REQ-053), no web font provides Tamil glyphs. The browser must fall back to whatever system fonts are installed on the device, resulting in inconsistent rendering across Android, iOS, Windows, and Linux.

---

## Impact
- **Who is hurt**: Mobile users downloading unnecessary font weights; Tamil users experiencing inconsistent system font fallbacks.
- **How**: 45.9 KB of wasted network bandwidth and uneven typographic rendering across client platforms.

---

## Repro Steps
1. Build client: `pnpm --filter client build`.
2. Inspect `client/dist/assets/*.woff2`.
3. Note presence of `cyrillic` and `vietnamese` font files.
4. Switch language toggle to Tamil in the UI and inspect computed `font-family`.
5. Observe font falls back to system generic `sans-serif`.

---

## Root Cause
- File: [`client/src/index.css`](file:///home/snehan/projects/web/mill-ledger/client/src/index.css#L1)
  - Importing `@fontsource-variable/geist` without specifying subsets pulls in all available unicode-range font files.
  - Tamil font package (e.g. `@fontsource/noto-sans-tamil`) was never installed.

---

## Recommended Fix (Do Not Apply)
1. In `client/src/index.css`, import only the latin subset:
   `@import "@fontsource-variable/geist/latin.css";`
2. Install and import `@fontsource/noto-sans-tamil` for consistent cross-platform Tamil typography.

---
