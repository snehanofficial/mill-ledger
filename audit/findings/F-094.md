## Delta
- Over 10 phantom dependencies bloat the lockfile and node_modules by dozens of megabytes without providing application value.
- 22 dead placeholder page components and 1 dead dictionary file remain in the source tree.
- 5.52% copy-paste duplication across frontend hooks and backend test harnesses.

---

## Impact
- **Security & Maintenance**: Phantom dependencies increase vulnerability scanner noise and supply-chain exposure.
- **Cognitive Load & Developer Confusion**: Developers encountering `placeholder-pages.tsx` or `i18n-dictionary.ts` will assume they are active systems, risking editing dead files instead of production code.

## Root Cause
- Rapid vibe coding during initial project scaffolding where packages (`cn`, `date-fns`, `react-hook-form`, `zod`, `shadcn`) and stub pages were added speculatively and never cleaned up when concrete implementations replaced them.

---

## Recommended Fix
1. Remove unused dependencies from `client/package.json` and `server/package.json`:
   ```bash
   pnpm --filter client remove @fontsource-variable/geist @hookform/resolvers cn date-fns next-themes react-day-picker react-hook-form shadcn tw-animate-css zod
   pnpm --filter @mill-ledger/server remove -D @types/supertest supertest
   ```
2. Delete orphaned file `client/src/lib/i18n-dictionary.ts`.
3. Purge the 22 unused exports from `client/src/pages/placeholder-pages.tsx`, retaining only necessary placeholders.
4. Consolidate `use-connection-status.ts` into `offline/use-offline.ts`.
5. Mount or remove `requireTenant` in `server/src/middleware/auth.middleware.ts`.
