# Finding F-037: Core Invoicing Workflow Cannot Be Initiated From Client UI (Missing Create Invoice Button)

**ID**: F-037  
**Title**: Core Invoicing Workflow Cannot Be Initiated From Client UI (Missing Create Invoice Action)  
**Severity**: P1 (Broken or missing core workflow)  
**Category**: Frontend & Operational Flow  
**Standard refs**: REQ-026, REQ-028, NN/g Heuristic #1 & #3  

---

## 1. Expected vs Actual (E9 Triple)

- **EXPECTED (REQ-026 / Problem Statement Order-to-Invoice)**:
  Once a Sales Order is approved and inventory is reserved, factory administrators or accountants must be able to generate and post a GST sales invoice from the user interface.
- **ACTUAL (`client/src/` AST inspection and Playwright Journey J5 execution)**:
  There is zero UI affordance (no button, modal, or action handler) anywhere in the application to post an invoice.
  - On `/orders`: Approved orders show only `Completed` in the action column.
  - On `/invoices`: The page renders only a table of existing invoices and a Credit Note button. There is no `Generate Invoice` or `New Invoice` button.
  - On `/dispatch`: Dispatches can be recorded, but no invoice creation trigger exists.
  - Grep search `grep -rn 'post.*invoice' client/src/` confirms `POST /api/v1/finance/invoices` is never called anywhere in the client codebase.
- **DELTA**:
  The core business workflow "Order -> Approve -> **Invoice** -> Dispatch" is completely broken on the frontend. Invoices can only be created by calling the Express HTTP API directly via curl/Postman or via the database seed script.

---

## 2. Impact

- Factory administrators and mill accountants cannot issue GST invoices to customers through the web portal.
- Deliveries cannot be accompanied by statutory GST tax invoices generated by staff, blocking legitimate commercial dispatch under Indian GST Rule 46.

---

## 3. Repro Steps & Root Cause

1. Sign in as Admin (`admin@millledger.local`).
2. Navigate to `/orders`.
3. Approve a submitted sales order.
4. Attempt to find any button or action to generate an invoice for this order. No button exists.
5. Navigate to `/invoices`. Notice no `New Invoice` button exists.
6. **Root Cause**: `client/src/pages/orders-page.tsx:750-780` and `client/src/pages/invoices-page.tsx:142-156` omit UI controls that invoke `apiClient.post("/finance/invoices", { salesOrderId })`.

---

## 4. Recommended Fix (Do Not Apply)

1. Add an `Invoice Order` action button on approved orders in `client/src/pages/orders-page.tsx` that invokes `apiClient.post("/finance/invoices", { salesOrderId: order.id })`.
2. Add a `Generate Invoice` dialog on `/invoices` allowing selection of eligible approved orders.

---

## 5. Regression Test to Add
