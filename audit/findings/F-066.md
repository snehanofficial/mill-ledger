# Finding F-066: Outbox Sync Status Badges Display Text Without Status Icons

- **ID**: F-066
- **Title**: Outbox Sync Status Badges Display Text Without Status Icons
- **Severity**: P2
- **Category**: Accessibility / Visual Affordance
- **Standard Refs**:
  - W3C WCAG 2.2 Success Criterion 1.4.1 Use of Color (Level A)
  - Master Rulebook Phase 9 Requirement: "sync status (queued, syncing, synced, conflict, failed) with text AND icon, not color alone;"

---

## Expected Behavior
Per Master Rulebook Phase 9 and WCAG 2.2 SC 1.4.1:
All critical synchronization state indicators (`queued`, `syncing`, `synced`, `conflict`, `failed`) must communicate their status using BOTH text AND an explicit visual icon (e.g. checkmark, spinning cycle, alert triangle, clock), rather than relying on color or text alone.

---

## Actual Behavior
1. In `client/src/pages/orders-page.tsx:567-595` and `client/src/components/shell/device-outbox-sheet.tsx:195-225`:
   ```tsx
   {ord.status === "queued" && (
     <Badge
       variant="outline"
       className="bg-amber-500/10 text-amber-700 dark:text-amber-400 border-amber-500/20"
     >
       Waiting to sync
     </Badge>
   )}
   {ord.status === "syncing" && (
     <Badge
       variant="outline"
       className="bg-sky-500/10 text-sky-700 dark:text-sky-400 border-sky-500/20 animate-pulse"
     >
       Syncing...
     </Badge>
   )}
   {ord.status === "synced" && (
     <Badge variant="success">
       Synced: {ord.serverOrderNumber ?? "Accepted"}
     </Badge>
   )}
   {ord.status === "conflict" && (
     <Badge variant="danger">
       Conflict: {ord.lastErrorCode ?? "Rejected"}
     </Badge>
   )}
   ```
2. While the header `SyncIndicator` in `authenticated-shell.tsx:180-215` provides icons (`WifiOffIcon`, `RefreshCwIcon`, `CheckCircleIcon`, `AlertCircleIcon`), the outbox list badges on both the Orders page and the Device Outbox Sheet render text badges without any SVG icon.
3. Programmatic audit evidence in `audit/evidence/motion/metrics/feedback-patterns-audit.json`:
   - `outboxBadgesAudit.items`: all badge elements have `hasIcon: false`.

---

## Delta
Sync status badges in the outbox stream omit visual icons, leaving users with low literacy or cognitive processing differences without iconographic status cues.

---

## Impact
Shop floor salesmen in noisy, low-contrast mill environments cannot scan outbox synchronization states by visual icon glyph alone, increasing the risk of missing sync conflicts or unsubmitted orders.

---

## Repro Steps
1. Navigate to `/orders`.
2. Click the "Device outbox" tab or open the Device Outbox Sheet.
3. Inspect the status badges for local orders.
4. Observe that badges contain text only, with no icon rendered inside or beside the badge.

## Root Cause
- [orders-page.tsx:567-595](file:///home/snehan/projects/web/mill-ledger/client/src/pages/orders-page.tsx#L567-L595)

---

## Recommended Fix
Incorporate status icons into each badge state:
- `queued`: `<ClockIcon className="size-3 mr-1" aria-hidden /> Waiting to sync`
- `syncing`: `<RefreshCwIcon className="size-3 mr-1 animate-spin" aria-hidden /> Syncing...`
- `synced`: `<CheckCircle2Icon className="size-3 mr-1" aria-hidden /> Synced: ...`
- `conflict`: `<AlertTriangleIcon className="size-3 mr-1" aria-hidden /> Conflict: ...`
- `failed`: `<AlertCircleIcon className="size-3 mr-1" aria-hidden /> Failed`
