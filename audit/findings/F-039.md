# Finding F-039: Audit Log CSV Export Throws 400 Error ("Unknown report type: audit")

**ID**: F-039  
**Title**: Audit Log CSV Export Throws 400 Error ("Unknown report type: audit")  
**Severity**: P2 (Broken button / export crash)  
**Category**: Frontend & API Integration  
**Standard refs**: REQ-061 (Audit Trail Export), NN/g Heuristic #1  

---

## 1. Expected vs Actual (E9 Triple)

- **EXPECTED (REQ-061 / Reporting Contract)**:
  When an Administrator or Accountant views the System Audit Trail on `/reports/audit` and clicks the "Export CSV" button, the server must stream a CSV file containing all immutable audit events.
- **ACTUAL (`server/src/modules/reporting/reporting.service.ts:923-947` & Playwright Dead UI test)**:
  Clicking "Export CSV" on `/reports/audit` triggers an HTTP GET to `/api/v1/reports/audit/export?format=csv&organizationId=MILL`. The server responds with:
  `HTTP 400 Bad Request: {"error": "Unknown report type: audit"}`
  In the browser console, an unhandled Axios/Fetch error is logged: `Export failed AxiosError: Request failed with status code 400`.
- **DELTA**:
  The UI offers an "Export CSV" button for the audit trail, but the backend implementation completely omitted the `case "audit"` branch in `exportToCSV()`, crashing the export workflow.

---

## 2. Impact

- External financial auditors, GST officers, and internal accountants cannot export system audit logs for compliance reviews or offline forensic analysis.

---

## 3. Repro Steps & Root Cause

1. Sign in as Admin (`admin@millledger.local`).
2. Navigate to `/reports/audit`.
3. Click the "Export CSV" button in the page header.
4. Open Developer Tools Network & Console tabs.
5. Observe HTTP 400 response from `/api/v1/reports/audit/export?format=csv` with error body `{"error": "Unknown report type: audit"}`.
6. **Root Cause**: `server/src/modules/reporting/reporting.service.ts` line 923:
   ```ts
   switch (reportType.toLowerCase()) {
     case "sales": ...
     case "gst": ...
     case "purchase": ...
     case "stock": ...
     case "production": ...
     case "collections": ...
     case "receivables": ...
     default:
       throw new AppError(`Unknown report type: ${reportType}`, 400);
   }
   ```
   `case "audit"` is missing from the switch statement.

---

## 4. Recommended Fix (Do Not Apply)

- Add `case "audit"` to `reportingService.exportToCSV` switch block:
  ```ts
  case "audit":
    reportData = await auditService.getLogs(params);
    break;
  ```
