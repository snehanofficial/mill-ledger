# F-089: Missing `robots.txt` and `sitemap.xml` with Server Returning HTTP 200 HTML SPA Shell

- **ID**: F-089
- **Title**: Missing `robots.txt` and `sitemap.xml` with Server Returning HTTP 200 HTML SPA Shell
- **Severity**: P2
- **Category**: Technical SEO / Web Standards Compliance
- **Standard Refs**:
  - RFC 9309: Robots Exclusion Protocol (REP)
  - Sitemaps XML Protocol 0.9 (sitemaps.org)
  - Google Search Central: Create and Submit a Sitemap & Robots.txt Specifications
  - `Problem_Statement_Winter_Internship_Application_2026.md` Owner Decision 2 ("SEO Scope: Metadata, not public indexing... Public landing pages may be indexed")

---

## Expected (Source)
- **Source**: RFC 9309 and standard web infrastructure requirements:
  - Standard web servers hosting indexable or private domains must serve a valid plain-text `robots.txt` file at `/robots.txt` with MIME type `text/plain` indicating crawler crawl-delay and disallow paths (e.g. `Disallow: /dashboard`, `Disallow: /api/`).
  - Search crawlers requesting `/sitemap.xml` must receive a valid XML sitemap document with MIME type `application/xml` or `text/xml` containing canonical URLs.
  - Non-existent static files must return HTTP 404, never an HTML application shell.

## Delta
Neither `/robots.txt` nor `/sitemap.xml` exists. The server serves the HTML Single Page Application document with HTTP 200 for both URIs, confusing automated search bots and web crawlers.

---

## Impact
- **Who is hurt**: Search crawlers, security scanners, and site operators.
- **How**: Crawlers treat the HTML response as a syntax error in REP parsing, ignoring disallow rules. Search engine webmaster consoles report critical XML parse errors for sitemaps.

## Root Cause
- File: [`client/public/`](file:///home/snehan/projects/web/mill-ledger/client/public/)
  - No `robots.txt` or `sitemap.xml` static assets were created.
- File: Production static server / Vite SPA configuration:
  - Unconditionally falls back to `index.html` with status 200 for any unrecognized route, including standard well-known static paths.

## Recommended Fix (Do Not Apply)
1. Add `client/public/robots.txt`:
   ```text
   User-agent: *
   Disallow: /dashboard/
   Disallow: /orders/
   Disallow: /stock/
   Disallow: /purchases/
   Disallow: /production/
   Disallow: /invoices/
   Disallow: /dispatch/
   Disallow: /payments/
   Disallow: /customers/
   Disallow: /reports/
   Disallow: /settings/
   Disallow: /exports/
   Disallow: /showcase
   Disallow: /api/
   Allow: /auth/login
   Allow: /
   Sitemap: https://millledger.local/sitemap.xml
   ```
2. Add `client/public/sitemap.xml`:
   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
     <url>
       <loc>https://millledger.local/auth/login</loc>
       <changefreq>monthly</changefreq>
       <priority>0.8</priority>
     </url>
   </urlset>
   ```
