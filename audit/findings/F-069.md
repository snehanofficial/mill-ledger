# Finding F-069: Missing Scroll Restoration on Route Navigation

- **ID**: F-069
- **Title**: Missing Scroll Restoration on Route Navigation in `<main>` Container
- **Severity**: P2
- **Category**: Usability / SPA Navigation
- **Standard Refs**:
  - React Router DOM Scroll Restoration Specification (`<ScrollRestoration />`)
  - NN/g: Scrolling and Navigation Usability Heuristics
  - Master Rulebook Phase 9 Requirement: "Page and route transitions: focus management is kept, scroll position handled, no blank flash."

---

## Expected Behavior
Per Master Rulebook Phase 9:
When navigating to a new route in a single-page application, the scroll position of the scrollable viewport container must reset to the top (`scrollTop = 0`), and when using the browser back/forward buttons, the user's prior scroll position must be restored.

---

## Actual Behavior
1. In `client/src/app.tsx`, the `router` configuration does not include `<ScrollRestoration />`.
2. Furthermore, in `client/src/components/shell/authenticated-shell.tsx:1180`, the page scroll container is NOT the `window`, but rather `<main id="main-content" className="flex flex-1 flex-col min-h-0 overflow-y-auto overflow-x-hidden ...">`.
3. Even if `<ScrollRestoration />` were added to the root router, React Router's default implementation only monitors `window.scrollY`. Because `#main-content` is an internal `overflow-y: auto` scroll container, navigating between views does not automatically reset `#main-content.scrollTop` to 0.
4. If a user scrolls down on `/orders` (e.g. 500px) and clicks a link in the sidebar or bottom mobile nav, the new page mounts with the scroll container pre-scrolled down, disorienting the user.

---

## Delta
The application lacks custom scroll handling for the `#main-content` internal scroll container, leading to stale vertical scroll offsets across route transitions.

---

## Impact
Users navigating between pages with long tables or lists find themselves dropped in the middle or bottom of the newly navigated page rather than at the top title and primary actions.

---

## Repro Steps
1. Navigate to `/orders`.
2. Scroll `#main-content` down by 400px.
3. Click "Stock" in the mobile bottom navigation or sidebar.
4. Observe that the Stock page opens with `#main-content` scrolled down, obscuring the page title and search filter until scrolled up manually.

---

## Root Cause
- [app.tsx:180-210](file:///home/snehan/projects/web/mill-ledger/client/src/app.tsx#L180-L210)
- [authenticated-shell.tsx:1180](file:///home/snehan/projects/web/mill-ledger/client/src/components/shell/authenticated-shell.tsx#L1180)

---

## Recommended Fix
Add a scroll reset effect in `client/src/layouts/authenticated-layout.tsx` targeting the `#main-content` container:
```tsx
useEffect(() => {
  const main = document.getElementById("main-content");
  if (main) {
    main.scrollTop = 0;
  }
}, [location.pathname]);
```
