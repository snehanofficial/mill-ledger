# Finding F-038: Suppliers Master Cannot Be Added or Managed via UI or API (Static Seed-Only Entity)

**ID**: F-038  
**Title**: Suppliers Master Cannot Be Added or Managed via UI or API (Static Seed-Only Entity)  
**Severity**: P1 (Missing core master data capability)  
**Category**: Domain & Master Data Management  
**Standard refs**: REQ-056 (All 10 Master Entities Management), NN/g Heuristic #3  

---

## 1. Expected vs Actual (E9 Triple)

- **EXPECTED (REQ-056 / Master Project Plan Section 3)**:
  Procurement managers and owners must be able to create, view, update, and manage raw material suppliers and mandi vendors through both the REST API and the frontend UI.
- **ACTUAL (`server/src/modules/inventory/inventory.routes.ts` & `client/src/pages/purchases-page.tsx`)**:
  - In Express API: Only `GET /api/v1/inventory/suppliers` exists (`inventory.routes.ts:76`). There is NO `POST /suppliers`, NO `PUT /suppliers/:id`, and NO `DELETE /suppliers/:id`.
  - In Client UI: There is no `/suppliers` page, route, or navigation link. On `/purchases`, suppliers only appear as pre-populated options in a modal `<select>` dropdown.
- **DELTA**:
  Suppliers cannot be created or edited by any user in production. New mandi vendors, flour suppliers, or spice merchants can only be inserted by directly executing SQL or re-running database seed scripts.

---

## 2. Impact

- Procurement operations are halted when new mandi vendors or suppliers deliver raw materials not present in the initial database seed.
- Mill staff are forced to request developer intervention or execute direct database writes to add suppliers, violating segregation of duties.

---

## 3. Repro Steps & Root Cause

1. Sign in as Admin (`admin@millledger.local`) or Owner (`owner@millledger.local`).
2. Search sidebar navigation for "Suppliers". No item exists.
3. Navigate to `/purchases` and open "Record Purchase Receipt".
4. Observe the supplier selection dropdown. Notice there is no "Add New Supplier" option or link.
5. Send HTTP `POST /api/v1/inventory/suppliers`. Server responds with `404 Not Found`.
6. **Root Cause**: `server/src/modules/inventory/inventory.routes.ts` does not define `createSupplier` or `updateSupplier` endpoints, and `client/src/app.tsx` does not define a suppliers route.

---

## 4. Recommended Fix (Do Not Apply)

1. Add `POST /api/v1/inventory/suppliers` and `PUT /api/v1/inventory/suppliers/:id` to `server/src/modules/inventory/inventory.routes.ts`.
2. Build a dedicated `SuppliersPage` in `client/src/pages/suppliers-page.tsx` with search, filter, and create supplier modal.
3. Expose a `/suppliers` navigation item in `nav-config.tsx` under Inventory.

---

## 5. Regression Test to Add
