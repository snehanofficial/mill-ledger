# Finding F-002: README Quick Start Path and Port Discrepancies

**ID**: F-002  
**Title**: README instructions specify nonexistent `server/.env.example` path and incorrect backend port 3000  
**Severity**: P2  
**Category**: Documentation Drift / Onboarding  
**Standard Refs**: NN/g Heuristic #10 (Help and Documentation)  
**Status**: OPEN  

---

### Expected (source)
`README.md` lines 29-30, 40:
- "Copy server environment template and verify DATABASE_URL: `cp server/.env.example server/.env`"
- "the backend API runs at http://localhost:3000"

### Actual (evidence links)
- Running `cp server/.env.example server/.env` fails with `cp: cannot stat 'server/.env.example': No such file or directory`.
- The actual template is at `.env.example` in the workspace root.
- The actual backend port defined in `.env.example`, `server/.env`, `client/vite.config.ts`, and runtime output is `4000`, NOT `3000`.
- Evidence log: [audit/evidence/02-cp-env.txt](file:///home/snehan/projects/web/mill-ledger/audit/evidence/02-cp-env.txt) and [audit/evidence/05-pnpm-dev.txt](file:///home/snehan/projects/web/mill-ledger/audit/evidence/05-pnpm-dev.txt).

### Delta
- Template path is `./.env.example`, not `server/.env.example`.
- Backend port is 4000, not 3000.

### Impact
New developers and evaluators following README step 2 fail immediately upon initial onboarding command. Any external integration assuming port 3000 will fail connection.

### Repro Steps
1. Execute `cp server/.env.example server/.env` in fresh repository.
2. Command fails with error.

### Root Cause
File: [README.md](file:///home/snehan/projects/web/mill-ledger/README.md#L30-L40)
Lines 30 and 40 contain stale paths and ports from earlier project scaffold.

### Recommended Fix (DO NOT APPLY - AUDIT ONLY)
Update `README.md` to:
`cp .env.example server/.env`
and update backend port reference from 3000 to 4000.

Script checking README codeblocks against file existence and environment defaults.
