# F-049: Complete Absence of In-App Documentation, Onboarding Guidance, and Domain Jargon Tooltips

- **ID**: F-049
- **Title**: Complete Absence of In-App Documentation, Onboarding Guidance, and Domain Jargon Tooltips
- **Severity**: P2
- **Category**: UX / Help & Documentation / Learnability
- **Standard refs**: NN/g H10 (Help and Documentation), Phase 7 Specification Check 10

---

## 1. Expected vs Actual

- **EXPECTED (Phase 7 Spec Check 10, UI-UX-Spec)**:
  1. The application shell must provide an accessible link to user documentation or operational manuals.
  2. First-time users or empty workspaces must offer onboarding guidance explaining the workflow sequence (e.g. Suppliers -> Purchases -> Production -> Sales Orders -> Invoices -> Payments).
  3. Complex food manufacturing and accounting domain jargon—including BOM (Bill of Materials), ATP (Available to Promise), FIFO (First-In, First-Out), and Yield Variance—must feature informative tooltips on table column headers and form labels.
- **ACTUAL (evidence: `client/src/components/shell/authenticated-shell.tsx`, `client/src/pages/reports-page.tsx:505`, `client/src/pages/production-page.tsx:392`, `client/src/pages/payments-page.tsx:975`)**:
  1. Zero links to documentation, user guides, or help systems exist in the app shell, sidebar, or user menu.
  2. Zero first-run wizards or onboarding guides exist. Empty states provide static text without explaining the upstream prerequisites (e.g. why no orders appear or how to seed inventory).
  3. Domain acronyms (BOM, ATP, FIFO, Yield variance) are presented as plain text headers without `<Tooltip>` wrappers or contextual explanations.
- **DELTA**:
  Help and documentation heuristic H10 is completely unaddressed in the frontend codebase.

---

## 2. Impact

- **Who is hurt**: Newly hired clerks, mill floor supervisors, and accountants unfamiliar with MillLedger's specific inventory calculation methodologies.
- **Operational consequence**: Confusion over whether "ATP" includes unapproved batches; misunderstanding how "FIFO automatic mode" allocates customer payments across multiple overdue invoices.

---

## 3. Repro Steps & Root Cause

### Repro Steps
1. Navigate to `http://127.0.0.1:4173/production/today` or `http://127.0.0.1:4173/reports/production`.
2. Hover over the column header "Yield variance". Observe: No tooltip appears; nothing explains how the percentage is derived.
3. Navigate to `http://127.0.0.1:4173/payments`. Open "Record payment" modal. Observe "Automatic FIFO mode": no explanation or tooltip on hover.
4. Inspect sidebar and user profile dropdown: no "Help", "User Guide", or "Docs" menu item.

### Root Cause
1. `reports-page.tsx`, `production-page.tsx`, and `payments-page.tsx` render raw text in `<TableHead>` without wrapping acronyms in `<Tooltip>`.
2. Navigation shell omitted help links.

---

## 4. Recommended Fix & Regression Test

### Recommended Fix (Do Not Apply - Audit Only)
1. Add a `<HelpCircleIcon />` tooltip to domain acronyms (BOM, ATP, FIFO, Variance) with 1-sentence plain English explanations.
2. Add a "Documentation & Guide" link in the shell's user avatar dropdown menu.

### Regression Test to Add
- Add Playwright spec `tests/help-tooltips.spec.ts` asserting:
  - Table headers for "Yield variance" and "ATP" trigger visible tooltip popovers on hover.
  - Avatar menu includes a link pointing to documentation.
