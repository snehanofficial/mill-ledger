# F-076: Missing Intent-Based Route Prefetching on Hover or Idle for Lazy-Loaded Routes

- **ID**: F-076
- **Title**: Missing Intent-Based Route Prefetching on Hover or Idle for Lazy-Loaded Routes
- **Severity**: P2
- **Category**: Frontend Performance / Navigation Latency
- **Standard Refs**:
  - Phase 10 Audit Prompt Requirement #3
  - Google Web Vitals: Interaction to Next Paint (INP) and route transition delay heuristics (< 100ms perceived)

---

## Expected (Source)
- **Source**: Phase 10 Audit Prompt Requirement #3 (`audit/01-expected-spec.md` REQ-055).
- In addition to route-level code splitting via `React.lazy`, navigation controls should implement prefetch on intent (e.g. initiating dynamic chunk download on link `hover`, `focus`, or during browser `idle` via `requestIdleCallback`) so that when the user clicks a route, the code is already cached in memory or browser HTTP cache.

---

## Actual (Evidence Links)
- **Evidence**:
  - Playwright network inspection: [`route-waterfall-lazy-loading.json`](file:///home/snehan/projects/web/mill-ledger/audit/evidence/performance/waterfalls/route-waterfall-lazy-loading.json).
  - Code search in [`client/src/components/shell/authenticated-shell.tsx`](file:///home/snehan/projects/web/mill-ledger/client/src/components/shell/authenticated-shell.tsx) and [`client/src/app.tsx`](file:///home/snehan/projects/web/mill-ledger/client/src/app.tsx): Zero occurrences of `onMouseEnter`, `onPointerEnter`, `onFocus`, or `prefetch` on navigation links.
  - Test observation: Dwell time of 500ms on navigation links (`a[href="/invoices"]`, `a[href="/orders"]`) produced **0 preload requests**. Script download begins strictly *after* the `click` event fires.

---

## Delta
Prefetching on intent is completely unimplemented. Users navigating to unvisited routes experience an avoidable 300ms - 800ms delay while the dynamic chunk is requested, downloaded, and parsed across the network, triggering the `<RouteLoadingFallback />` spinner instead of an instantaneous route transition.

---

## Impact
- **Who is hurt**: Mill workers navigating between operational views (Stock -> Orders -> Dispatch -> Invoices).
- **How**: Laggy route transitions with visible loading spinner flickers during normal navigation.

---

## Repro Steps
1. Open Chrome DevTools Network panel on `http://127.0.0.1:4173/dashboard`.
2. Filter network panel by `JS`.
3. Hover cursor over the "Invoices" link in the sidebar for 2 seconds.
4. Observe zero network activity.
5. Click "Invoices".
6. Observe `invoices-page-*.js` starts downloading only after click.

---

## Root Cause
- File: [`client/src/components/shell/authenticated-shell.tsx`](file:///home/snehan/projects/web/mill-ledger/client/src/components/shell/authenticated-shell.tsx)
  - Navigation links are standard React Router `<Link>` components without `onMouseEnter` or `onPointerEnter` handlers that invoke route chunk factory functions.

---

## Recommended Fix (Do Not Apply)
1. Add an intent prefetch helper to route definitions:
   ```ts
   const routeImportMap = {
     "/invoices": () => import("@/pages/invoices-page"),
     "/orders": () => import("@/pages/orders-page"),
     ...
   };
   ```
2. Attach `onPointerEnter={() => routeImportMap[to]?.()}` to sidebar and bottom navigation links.
