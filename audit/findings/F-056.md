# F-056: Inadequate Color Contrast on Muted Text and Subtle Status Indicators

- **ID**: F-056
- **Title**: Inadequate Color Contrast on Muted Text and Subtle Status Indicators
- **Severity**: P2
- **Category**: Accessibility / Visual Presentation / Contrast
- **Standard refs**: WCAG 2.2 SC 1.4.3 (Contrast (Minimum) - Level AA)

---

## 1. Expected vs Actual

- **EXPECTED (WCAG 2.2 SC 1.4.3 Level AA)**:
  The visual presentation of text and images of text must have a contrast ratio of at least 4.5:1 against its background, except for large text (at least 18pt or 14pt bold), which requires 3:1.
- **ACTUAL (evidence: `client/src/pages/orders-page.tsx:516`, `client/src/index.css:20`, `audit/evidence/a11y/snapshots/comprehensive_wcag_verification.json`)**:
  While `--muted-foreground: #52525b` achieves 7.58:1 against white, multiple UI components apply secondary alpha-channel reduction classes, specifically `text-muted-foreground/60`:
  ```tsx
  {/* orders-page.tsx:516 */}
  <ShoppingCartIcon className="h-8 w-8 stroke-1 text-muted-foreground/60" />
  <p className="text-xs text-muted-foreground/60">No sales orders created yet.</p>
  ```
  At 60% opacity, `#52525b` renders visually as `#97979c` against the `#fcfdfc` / `#ffffff` surface.
  - Calculated luminance: `L = 0.308`.
  - Contrast ratio against white: **2.93:1** (violates the 4.5:1 requirement).
- **DELTA**:
  Opacity utility reduces contrast ratio to 2.93:1, falling significantly below the 4.5:1 AA threshold.

---

## 2. Impact

- **Who is hurt**: Low-vision users, elderly operators, and floor managers viewing mobile screens in bright mill warehouse sunlight.
- **Operational consequence**: Empty-state guidance and secondary status hints become unreadable or washed out.

---

## 3. Repro Steps & Root Cause

### Repro Steps
1. Navigate to `/orders` with an empty database or fresh session.
2. Inspect the empty state text ("No sales orders created yet.") in Chrome DevTools Elements.
3. Open CSS Color Picker -> Contrast ratio: displays `2.93` with red warning flag ("Does not meet WCAG AA standards").

### Root Cause
Applying arbitrary Tailwind opacity modifiers (`/60`, `/40`) to text elements that already use subdued muted palette tokens.

---

## 4. Recommended Fix & Regression Test

### Recommended Fix
Remove the `/60` opacity modifier from text elements; rely on full-strength `--muted-foreground` (`#52525b`, which has 7.58:1 contrast):
```tsx
<p className="text-xs text-muted-foreground">No sales orders created yet.</p>
```

### Regression Test
Run automated contrast calculation across all text nodes in Playwright: assert computed text color against effective background yields ratio `>= 4.5`.
