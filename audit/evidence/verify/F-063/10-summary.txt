1. Root Cause:
Desktop sidebar toggling transitioned CSS geometric `width` over 220ms (`transition-[width] duration-220`),
forcing layout recalculation and reflow on the adjacent main container and responsive tables during every frame.
Furthermore, Radix collapsible accordion open/close keyframes animated geometric `height` between 0 and
`var(--radix-collapsible-content-height)`, triggering layout-thrashing reflow of parent content.

2. Implementation Summary:
- `client/src/components/ui/sidebar.tsx`:
  * Removed `transition-[width] duration-220 ease-[cubic-bezier(0.2,0,0,1)]` from desktop sidebar container.
  * Replaced `SidebarRail`'s `transition-all` with non-layout `transition-colors duration-150`.
  * Preserved mobile drawer's GPU-composited `transition-transform` (`translateX`).
- `client/src/index.css`:
  * Re-architected `@keyframes collapsible-open` and `@keyframes collapsible-close` to animate GPU-composited
    properties (`opacity` and `transform: translateY(...)`) instead of mutating geometric `height`.
- Validated that 0 files across the client codebase now animate geometric width or height.
