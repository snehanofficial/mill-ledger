---------------------------
Finding: F-041: Unrestricted Report Tabs Cause 403 Console Errors for Scoped Roles (Salesman & Production)
Severity: P2
Tier: T5
Cluster: CLUSTER-08

Root Cause:
`client/src/pages/reports-page.tsx` rendered tabs for all reports regardless of user role, while backend reporting routes strictly enforce role scoping (SALESMAN -> sales, stock; PRODUCTION -> production, stock; OWNER/ADMIN/ACCOUNTANT/AUDITOR -> all). This caused 403 network errors in console when restricted users loaded or switched tabs.

Remediation:
1. Associated each report tab with allowed roles (`roles: Role[]`) in `REPORT_TABS` within `client/src/pages/reports-page.tsx`.
2. Consumed `useCurrentUser()` to identify current user role.
3. Filtered rendered tabs to only `allowedTabs` matching user's role.
4. Guaranteed `effectiveTab` defaults to the first permitted tab if active tab in search params is forbidden or unauthorized.
5. Conditioned React Query data hooks on `effectiveTab === tab.id` so unauthorized queries are never executed.
