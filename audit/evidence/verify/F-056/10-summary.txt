F-056 VERIFICATION SUMMARY: COLOR CONTRAST ON MUTED TEXT (WCAG 1.4.3)
======================================================================
Date: 2026-11-24
Severity: P2 | Tier: T7 | Cluster: CLUSTER-10
Status: VERIFIED-PASS

1. Root Cause:
While `--muted-foreground: #52525b` natively achieves a 7.72:1 contrast ratio against
light backgrounds, applying Tailwind opacity modifiers (`text-muted-foreground/60`,
`/50`, `/40`, `/70`) degraded the effective contrast ratio down to ~2.93:1 on white
surfaces, failing the WCAG 2.2 SC 1.4.3 Level AA requirement of at least 4.5:1.

2. Implementation Summary:
- Removed opacity reduction modifiers across all operational pages, empty states,
  and components:
  * `client/src/pages/orders-page.tsx`: ShoppingCartIcon empty state icon restored to full `text-muted-foreground`
  * `client/src/pages/invoices-page.tsx`: FileTextIcon empty state icon restored to full `text-muted-foreground`
  * `client/src/pages/dispatch-page.tsx`: TruckIcon empty state icon restored to full `text-muted-foreground`
  * `client/src/pages/production-page.tsx`: FactoryIcon empty state icon restored to full `text-muted-foreground`
  * `client/src/pages/purchases-page.tsx`: TruckIcon empty state icon restored to full `text-muted-foreground`
  * `client/src/pages/payments-page.tsx`: CreditCardIcon empty state icon restored to full `text-muted-foreground`
  * `client/src/pages/customers-page.tsx`: UsersIcon and MapPinIcon restored to full `text-muted-foreground`
  * `client/src/pages/new-order-page.tsx`: Slash divider restored to full `text-muted-foreground`
  * `client/src/components/ui/breadcrumb.tsx`: Breadcrumb separator icon restored to full `text-muted-foreground`
