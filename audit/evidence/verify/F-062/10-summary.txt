F-062 VERIFICATION SUMMARY: USER MOTION PAUSE MECHANISM (WCAG 2.2 SC 2.2.2 & APPLE HIG)
======================================================================
Date: 2026-11-24
Severity: P2 | Tier: T7 | Cluster: CLUSTER-11
Status: VERIFIED-PASS

1. Root Cause:
In `orders-page.tsx:890` and `device-outbox-sheet.tsx:205`, orders with status="syncing"
rendered continuous pulsing badges using Tailwind's infinite `animate-pulse` utility class.
Additionally, skeleton components and loading states lacked in-app pause/stop/hide controls,
causing infinite peripheral movement beyond the 5-second WCAG threshold without user control.

2. Implementation Summary:
- `client/src/hooks/use-motion.ts`:
  * Created custom hook managing `isMotionPaused` state synchronized with `localStorage`
    (`mill-ledger-motion-preference`) and OS-level `prefers-reduced-motion` media queries.
  * Toggles `html.motion-paused` and `html[data-reduce-motion="true"]` on `document.documentElement`.
- `client/src/index.css`:
  * Added global CSS overrides for `html[data-reduce-motion="true"]` and `html.motion-paused` to
    suppress transitions (`0.01ms`) and disable animations (`animation: none !important`).
  * Created `.animate-pulse-finite` CSS class limiting pulsing iterations to 2 cycles (4.0s max),
    strictly complying with the WCAG 2.2 SC 2.2.2 threshold (< 5 seconds).
- `client/src/components/ui/skeleton.tsx`:
  * Added `motion-reduce:animate-none` class to prevent skeleton pulse when reduced motion is preferred.
- `client/src/pages/orders-page.tsx` & `client/src/components/shell/device-outbox-sheet.tsx`:
  * Replaced infinite `animate-pulse` with `.animate-pulse-finite` on syncing badges.
- `client/src/components/shell/authenticated-shell.tsx`:
  * Added accessible global pause/resume button with `data-pause-motion`, `aria-label`, and `title`
    in the top header bar next to theme switcher, as well as in user dropdown menus.
- `client/src/pages/settings-page.tsx`:
  * Added Interface Motion & Accessibility preferences card under Mill Settings allowing user toggling.
- `client/src/lib/i18n.tsx`:
  * Added localized bilingual terms for animation pause/resume controls.
