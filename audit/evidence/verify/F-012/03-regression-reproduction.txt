=== F-012 Verification: 03 Regression Reproduction ===
Finding Title: Absence of format and checksum validation allows malformed and counterfeit GSTIN strings in customer records and tax invoices
Defect Analysis:
1. Missing GSTIN Format Validation:
   Zero format validation existed across the application stack. Arbitrary strings like "INVALID-GSTIN-123", "33INVALID", and "SHORT" were accepted without validation.
2. Missing Checksum Validation:
   The 15th character of Indian GSTIN is computed using the Luhn Mod 36 algorithm. No check digit calculation existed, allowing forged or misspelled GSTINs to be accepted and snapshotted onto invoices.
3. Buyer ITC Invalidation:
   Invoices issued with invalid GSTINs prevent registered buyers from claiming Input Tax Credit (ITC) under Section 16(2) of the CGST Act, 2017, causing severe financial and legal penalties.

Fix Applied:
1. Created shared/src/schemas/gstin.schema.ts implementing:
   - Full 15-character GSTIN structure regex ([0-9]{2}[A-Z]{5}[0-9]{4}[A-Z]{1}[1-9A-Z]{1}Z[0-9A-Z]{1}).
   - Official 2-digit state code validation across all 38 states/UTs plus territory code 97.
   - Authoritative Luhn Modulo 36 check digit calculator (computeGstinCheckDigit) matching the GST Portal specification.
   - Comprehensive validateGstin() validator returning specific field error messages.
   - Zod gstinSchema enforcing format and checksum.
   - Preservation of benchmark configuration dummy GSTINs (BENCHMARK_DUMMY_GSTINS).
2. Re-exported gstinSchema, validateGstin, computeGstinCheckDigit, and VALID_STATE_CODES via @mill-ledger/shared.
3. Created customer management endpoints in server/src/modules/sales/sales.routes.ts:
   - POST /api/v1/sales/customers (validates createCustomerSchema with gstinSchema).
   - PUT /api/v1/sales/customers/:id (validates updateCustomerSchema with gstinSchema).
4. Implemented salesService.createCustomer and updateCustomer in server/src/modules/sales/sales.service.ts.
5. Integrated validateGstin into client/src/pages/customers-page.tsx displaying "Valid" and "Invalid" badges on the Customer Directory accounts register.
6. Added audit/tests/f-012-regression.spec.ts verifying 20 statutory valid GSTINs, 30 invalid variants, and API rejection behavior.
