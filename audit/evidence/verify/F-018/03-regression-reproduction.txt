=== F-018 VERIFICATION EVIDENCE 03: REGRESSION REPRODUCTION ===
Finding ID: F-018
Title: `GET /api/v1/sales/dispatches` is accessible to salesmen and leaks company-wide customer orders, invoices, and dispatch records
Severity: P1
Category: Authorization / BOLA / Information Disclosure
Standard Refs: OWASP API Security Top 10:2023 API1:2023 (Broken Object Level Authorization), OWASP Top 10:2021 A01:2021 (Broken Access Control)
Owner Decision Ref: OD-03 (Scoped Dispatches)

Root Cause:
1. `server/src/modules/sales/sales.routes.ts`: `GET /dispatches` authorized `order:read`, which the `SALESMAN` role holds. However, the route called `dispatchService.getDispatches(orgId)` without passing `req.user`.
2. `server/src/modules/sales/dispatch.service.ts`: `getDispatches(organizationId)` queried all dispatches for the organization without any salesman ownership filter. This leaked all commercial dispatches across all accounts, disclosing client identities, invoice numbers, vehicle numbers, and shipment quantities.

Reproduction & Verification:
- Repro: Authenticate as Salesman 1, query `GET /api/v1/sales/dispatches`. Prior to the fix, Salesman 1 received dispatches belonging to other salesmen (e.g. Salesman 2's Distributor B dispatches).
- Fix per Owner Decision OD-03 (Option B):
  * Updated `dispatchService.getDispatches(organizationId, user)`: when `user.role === "SALESMAN"`, adds filter `where.salesOrder = { salesmanId: user.id }`.
  * Added `dispatchService.getDispatchById(dispatchId, user)`: enforces the same ABAC salesman check on single-record lookups, returning 404 if accessed by an unauthorized salesman.
  * Preserved full organization-wide visibility for `ADMIN`, `DISPATCHER`, and `OWNER`.
- Verified in `server/src/invoice-dispatch.test.ts` (Test 4):
  * Salesman 1 lists dispatches -> returns only Dispatch 1 (Retailer A), does not return Dispatch 2 (Distributor B).
  * Salesman 1 requests `GET /api/v1/sales/dispatches/:dispatch2Id` -> HTTP 404 Not Found.
  * Salesman 2 lists dispatches -> returns only Dispatch 2, does not return Dispatch 1.
  * Salesman 2 requests `GET /api/v1/sales/dispatches/:dispatch1Id` -> HTTP 404 Not Found.
  * Admin lists dispatches -> returns both Dispatch 1 and Dispatch 2.
