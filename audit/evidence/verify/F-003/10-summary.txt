1. Root Cause:
`server/prisma.config.ts` declared `schema` and `datasource.url` in `defineConfig()`, but omitted
the `migrations.seed` property required by Prisma 7 CLI. Running `pnpm --filter @mill-ledger/server prisma db seed`
emitted a warning that no seed command was configured and exited with code 0 without inserting any records,
leaving a clean database completely empty.

2. Implementation Summary:
- `server/prisma.config.ts`:

  * Verified that `pnpm --filter @mill-ledger/server prisma db seed` runs `tsx ./prisma/seed.ts`
    and successfully seeds M1 test users and M2 benchmark master data.
