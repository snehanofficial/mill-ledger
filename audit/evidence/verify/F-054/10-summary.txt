F-054 VERIFICATION SUMMARY: LABEL IN NAME MISMATCH (WCAG 2.5.3)
======================================================================
Date: 2026-11-24
Severity: P2 | Tier: T7 | Cluster: CLUSTER-10
Status: VERIFIED-PASS

1. Root Cause:
On `/auth/login`, the language switcher button visually rendered "தமிழ்" (when English)
and "English" (when Tamil), but its `aria-label` was hardcoded to "Switch language to Tamil"
and "ஆங்கிலத்திற்கு மாற்று" respectively. The visible text was completely absent from
the accessible name, causing Lighthouse `label-content-name-mismatch` failures and
breaking voice navigation / speech control users (WCAG 2.2 SC 2.5.3 Level A).

2. Implementation Summary:
- Modified `client/src/pages/login-page.tsx`:
  * Updated `aria-label` to "தமிழ் (Switch language to Tamil)" when language is "en"
  * Updated `aria-label` to "English (ஆங்கிலத்திற்கு மாற்று)" when language is "ta"
- Satisfied WCAG 2.2 SC 2.5.3 Level A requirement: the accessible name begins with
  and contains the exact visible label text.
- Verified authenticated shell language button already conforms to WCAG 2.5.3:
  * "தமிழ் - Switch language to Tamil" (matches "தமிழ்")
  * "EN - Switch language to English" (matches "EN")
