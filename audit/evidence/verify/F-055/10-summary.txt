1. Root Cause:
- `SidebarRail` in `client/src/components/ui/sidebar.tsx` had a bounding width of 16px (`w-4`),
  directly violating WCAG 2.2 SC 2.5.8 (Level AA minimum 24x24 CSS pixels).
- Breadcrumb navigation links had a target height of only 20px.
- Table action buttons and compact outbox action buttons used `h-6` (24px) and `h-7` (28px)
  with sub-optimal tap dimensions for mobile/handheld touchscreens (Apple HIG 44x44px).

2. Implementation Summary:
- Modified `client/src/components/ui/sidebar.tsx`:
  * Updated `SidebarRail` width to `w-6 min-w-6` (24px width), satisfying WCAG 2.5.8 Level AA.
- Modified `client/src/components/ui/breadcrumb.tsx`:
  * Added `min-h-6 min-w-6 inline-flex items-center py-0.5` to `BreadcrumbLink`, ensuring >= 24px height.
- Modified `client/src/components/ui/button.tsx`:
  * Added `touch-manipulation` to `buttonVariants` for fast and responsive mobile interactions.
- Modified `client/src/index.css`:
  * Defined `.touch-target` utility class ensuring `min-height: 44px; min-width: 44px;` per Apple HIG.
- Upgraded compact table and sheet action buttons:
  * `client/src/components/shell/device-outbox-sheet.tsx`: Upgraded from `h-6` to `h-8 min-h-[32px] px-2.5 sm:h-7 sm:min-h-[28px] sm:px-2`.
  * `client/src/pages/orders-page.tsx`: Upgraded outbox actions and approve/reject table actions to `h-8 min-h-[32px]`.
  * `client/src/pages/invoices-page.tsx`: Upgraded view and credit note table buttons to `h-8 min-h-[32px] sm:h-7`.
  * `client/src/pages/suppliers-page.tsx`: Upgraded edit button to `h-8 min-h-[32px] sm:h-7`.
  * `client/src/components/shell/authenticated-shell.tsx`: Upgraded sync, outbox, mark all read, and clear notifications buttons to `h-8 min-h-[32px]` / `size-8 min-h-8 min-w-8`.
