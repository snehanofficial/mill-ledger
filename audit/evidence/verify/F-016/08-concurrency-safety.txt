=== F-016 VERIFICATION EVIDENCE 08: CONCURRENCY SAFETY ===
Timestamp: 2026-11-23T14:49:45+05:30
Scope: Atomic production posting, row locking, and idempotency

1. Pessimistic Row Locking:
- Material item row lock: `SELECT id, name, sku, category, "baseUomId", "currentStock", "weightedAverageCost" FROM "inventory_item" WHERE id = $1 FOR UPDATE`.
- Guarantees concurrent production runs or inventory movements cannot interleave and oversell inventory.

2. Idempotency Key Guarantees:
- `production_run` enforces unique constraint on `idempotencyKey`.
- If two concurrent requests submit the same `idempotencyKey`, only one executes the transaction; the duplicate safely returns the posted run without re-deducting materials or duplicate finished goods stock movements.
- Verified in `server/src/concurrency-idempotency.test.ts` and `server/src/production.service.ts:213-234`.
